## Outcome and scope decision

The first surface is the existing Bitwig MCP entrypoint. Its 57-tool registry
is the single source of tool names, schemas, policies and dispatch behavior.
BITWIG_MCP_TOOL_DISCOVERY=1 adds search_tools and call_tool alongside permitted
direct tools. Default metadata, historical registry and schemas are unchanged.
NanoDAW MCP and the provider's three-tool projection are unchanged.

Search performs bounded literal matching and paging over policy-enabled
definitions, without inspecting a DAW. Results carry names/descriptions/schemas/
policies and honest pagination; policy availability is not live readiness.

Generic dispatch validates the wrapper and target schemas using the existing
MCP SDK validator, then delegates to handleToolCall. It preserves the current
write-policy check, bridge authentication flag, target output and errors. It
cannot invoke another generic tool or a name outside the registry.
No new dependency, runtime configuration change, provider call or DAW write.

## Adversarial review

- Default listing and the frozen 57-tool schema snapshot still match.
- Wrapper arguments are bounded to 64 KiB of JSON; query/page inputs are bounded.
- Unknown fields cannot override env, policy, method or authentication.
- A disabled write is omitted from discovery and blocked on direct guessing.
- Schemas reject wrong target types without coercion; malformed arguments never dispatch.
- Policy revocation across asynchronous validation is checked by canonical dispatch.
- Recursive wrappers and unknown/cross-surface targets are rejected.
- The caller is conservatively marked potentially destructive/non-idempotent.
- A lost target reply produces one error and no retry.
- In-memory MCP client/server tests exercise the actual protocol handlers.

No confirmed remaining defect from this review. This slice does not add a
central multi-server router or extend NanoDAW's confirmation/execution surface.
Target schemas retain their historical semantics and controller-side bounds;
discovery is not a new universal musical-argument validator or approval system.
